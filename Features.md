
## Features 

- **Login** 
- Admin can login with username with password
- Admin can only create customer
- Admin can only create goods and service


- **Customer** 
    
- Create a customer 
- Edit Customer Details 
- Delete customer Details 
- List out All Customer's details 
- Add alert message

- **Invoice** 

- Create Invoice Detail
- Edit Invoice Details
- Delete Details
- List out All Invoice Details 
- Add alert message 
- Generate Invoice Number
- Invoice & Due Date 
- Generate PDF File 
- Download PDF File

- **Goods**

- Create goods 
- Edit goods 
- Delete goods 
- List out all goods 
- Alert message 
- Search functionality 
- Pagination

- **Service**
- Create service 
- Edit service 
- Delete service 
- List out all service 
- Alert message 
- Search functionality 
- Pagination

      
- **Rest API**
- Create Invoice by API
- Accept GET & POST Methods
- serializer created
